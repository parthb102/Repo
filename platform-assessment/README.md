# Platform Assessment Tracker

`Platform_Assessment_Tracker.xlsx` is generated by `build_assessment_workbook.py`
(requires `openpyxl`). It implements the gateway-style platform assessment from
the strategy slide across all capabilities:

- **Summary tab** — capability / sub-capability roll-up with live Tranche 1/2/3
  counts and `Open →` links into each section.
- **One tab per capability** (Boarding, Single-in, Sales & Servicing, Payment
  Processing, VAS, Unified Data and AI, Global Infrastructure, Single-out),
  each with a clickable tracker at the top that jumps to the sub-capability
  sections.
- **Per sub-capability**: a platform table (① numbering, State dropdown,
  Imperative to exit / Exit complexity dropdowns, Supporting facts, auto
  Tranche) plus a benefits-vs-complexity matrix styled like the slide.
  Target-state / Exception rows gray out and drop off the matrix; bubbles
  (ID + platform name) re-plot live as scores change.

Tranche rules: Low complexity → Tranche 1; Medium complexity → Tranche 2;
High complexity + High imperative → Tranche 3; Low imperative (or Medium
imperative + High complexity) → no tranche.

Payment Processing → Gateway is pre-seeded with the slide's illustrative
examples. No macros; needs desktop Excel 2016+. To regenerate:

```bash
pip install openpyxl
python3 build_assessment_workbook.py
```
