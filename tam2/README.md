# TAM 2.0 — absorbed knowledge base

Working notes distilled from TAM 2.0 programme materials (Global Payments ×
Worldpay platform-integration programme). Each "absorption" session reads the
newest source documents, distils them into these notes, and drops the originals
into `sources/` so later sessions can re-query cell-level detail.

## Contents

| File | What it covers |
|---|---|
| `program-context.md` | Programme framing, workbook structure, operating principles, back-book considerations |
| `enterprise-sequencing.md` | Enterprise segment — NA and RoW (excl. LATAM) |
| `integrated-sequencing.md` | Integrated (platforms/ISV) segment — NA and RoW |
| `smb-sequencing.md` | SMB segment — UK&I, NA (Direct / Wholesale / Indirect / ISO), RoW |
| `cross-segment.md` | First-mover decisions, shared target platforms, key dates, open decisions |
| `glossary.md` | Platform names and acronyms (marked where inferred) |
| `meetings/` | Distilled minutes from workshop recordings |
| `sources/` | Original workbooks / transcripts as uploaded |
